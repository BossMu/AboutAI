# agent规则

## 语言

- 用中文交流。

## 通用规则

- 根路径统一用变量 $base_url 表示，本 agent 固定为 ~/.codex
- 默认浏览器使用 Edge

## Agent & skills 技能规则

- 使用 agent 或 skills 等技能时，在结果展示的时候要告知用户用了什么。
- 使用 agent 或 skills 等技能时，可以主动发现问题、提出优化方案，并进行自我完善方向的判断与建议。
- 凡涉及对 agent、skills 或相关规则内容的实际修改，必须先征求用户确认，只有在用户明确同意后，才能执行修改。


## 文件目录操作规则

- 目录结构维护在Dir.md
- 修改本文件(规则文件)时必须要先展示对比，确认后在修改
- 删除任何文件前，必须明确列出将要删除的每一个文件，并先向用户发起确认后再删除，回复 ok 即可。
- 对于放错位置需要移动、改名字、统一命名规范、或按规则迁移文件这类情况，不需要再次确认。改名或移动过程中旧路径消失，视为改名或迁移的一部分，不单独视为删除。
- 执行文件操作时，应优先收敛到唯一正确文件，避免同一份内容在错误命名或错误路径下重复保存。
