## 一、完整业务规则（持仓卖出策略模块）

### 卖出方法（必须严格遵循）
| 序号 | 场景描述 | 标准操作建议 |
|------|------|------|
| **第一种** | 连续几天量能不足，股价无法创新高 | **减仓观察** |
| **第二种** | 大阳线后高开低走放量阴线 | **直接清仓** |
| **第三种** | 股价跌破中期重要支撑位，或跌破近期大阳线的实体低点 | **用户实战总结优化：破位第一天先减仓一半（留一半观察），确认继续破位再清仓**，避免主力骗线洗盘；止损票需要提示用户从股票池移除 |
| **第四种（创业板股票的特殊规则）** | 当天拉升10个点以上的大阳线，但是没封死涨停 | **即可清仓或大幅减仓** |
| **第五种（用户新增纪律）** | **前一天涨停板的票，若是今日未涨停** | **即可卖出（减仓/清仓根据仓位确定）** |

### 卖出原则
- 严格执行：几种场景严格对应操作，不犹豫
- 分级止盈：符合第一种场景建议减仓，不一次性清仓
- 形态破坏立即走人：跌破支撑/放量大阴线立即走人不犹豫
- 止损后：提示用户需要从股票池移除，**必须经用户二次确认**后由 stockwin 总 skill 执行对应文件更新

## 二、卖出分析流程

### 第一步：基于 stockwin 总 skill 提供的最新行情
- 使用 stockwin 总 skill 提供的最新实时行情分析

### 第二步：逐个分析卖出决策
按以下顺序分析，对号入座：

**优先级：资金面 > 技术面 > 消息面**

1. **资金面分析**
   - 成交量是否异常放大（主力出货信号）
   - 成交量是否持续萎缩（资金流出信号）
   - 量价配合是否变坏
   - 判断是否符合"连续量能不足无法创新高"

2. **技术面分析**
   - 使用上述【卖出原则】给出结论

3. **消息面分析**
   - 基于 stockwin 总 skill 提供的消息，分析是否有重大利空
   - 必须先写明该股**所属行业**，再列出 **2-4 个核心概念**
   - 在明确归属后，再判断所属行业和核心概念板块是否已经走坏，以及这是否构成卖出理由

### 第三步：给出结论
- 根据上述几种场景对号入座，明确给出操作建议
- 止损票提示需要从股票池移除，由 stockwin 总 skill 在用户确认后执行对应文件更新
