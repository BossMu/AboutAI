## 一、完整业务规则（持仓分析模块）

### 分析流程要求
- 由 stockwin 总 skill 提供完成前置校验后的数据，本模块按照分析框架输出分析结论

### 仓位管理原则
- 推荐持仓个股数量**不超过6只**，超过6只时必须明确提示用户分散过度，建议适当减仓缩圈，聚焦核心标的
- 每只股票的仓位不能超过4成
- 根据大盘的整体情况给予仓位管理建议和分析，主升浪期间可以7成以上，震荡期可以使5-7成，下跌期间风险较高的时候要求5成以下，在超跌反弹无力的时候也要提示减仓风险(该内容高亮提醒)


## 二、完整分析流程（stockwin输出内容）

### 第一步：大盘分析（基于 stockwin 总 skill 提供的行情数据）
1. **日期规则：** 如果当日是交易日，分析当日大盘数据；如果当日是非交易日（周末/节假日），则分析**上个交易日**的大盘数据，必须明确标注分析的是哪一天的数据
2. 分析内容：
   - 分板块用表格列出各指数，包含**涨跌幅+当日成交额+环比变化**（必须分成四个板块分别列出：上证、深证、创业板、000680 科创综指，不得只给合计数据）
   - 整体成交额判断（放量/缩量幅度）
   - 当日市场涨跌停家数概况(剔除st股票)
   - 当前主流热点板块分析
   - 总结大盘环境对持仓的影响

### 第二步：逐只个股分析（基于 stockwin 总 skill 提供的个股行情和消息）
1、个股分析要求
	- 严格分析优先级：资金面 > 技术面 > 基本面 > 消息面
	- 技术面分析可以参考【技术形态】章节，不要完全依赖这个章节，你可以加入自己的思考
	- 分析基本面时必须展示近三年的营业收入（含同比）、净利润（含同比）、净资产，并且用表格形式展示
	- 分析“概念板块”时，必须按固定结构输出：先写**所属行业**，再写 **2-4 个核心概念**，最后分析行业/概念板块的强弱、联动性及其对个股的影响
	- 不允许只写“板块表现尚可/一般/偏弱”等笼统判断，必须先明确归属再展开分析
	
2、个股分析内容
| 模块 | 分析内容 |
|------|----------|
| **基本信息** | 代码、名称、最新价、今日涨跌幅、持仓成本/数量/累计盈亏 等数据 |
| **概念板块** | 必须先写明**所属行业**，再列出 **2-4 个核心概念**，然后分析这些行业/概念的整体表现、板块效应、联动性，以及对个股的正负影响（概念板块行情由 stockwin 总 skill 提供） |
| **资金面**（最重要） | 近期成交量变化、今日换手率、量价配合健康度、资金博弈方向 |
| **技术面** | 位置（高/中/低）、支撑位、压力位、趋势判断、**明确止损价+明确止盈价** |
| **基本面** | 先说明公司**核心主营业务**，再重点展示**近2年的营业收入（含同比）、净利润（含同比）、净资产**数据，评估盈利能力、成长潜力与财务稳健性；必须排查 **ST风险/退市风险**，若存在风险必须**高亮警示** |
| **消息面** | 基于 stockwin 总 skill 提供的消息，分析公告/题材/风险，并结合前文已明确的行业和核心概念，判断板块催化或板块拖累是否影响个股表现 |
| **估值分析** | 基于公司主营业务、业绩情况、行业发展前景，参考研报和行业的PE区间，给出合理估值，预测合理市值和目标股价 |
| **买入评估** | 针对现价买入进行风险收益评估，明确分析：买入的有利因素/风险因素，给出明确观点：适合买入/观望/不建议追高，区分中长期配置和短线投机不同情况给出建议 |
| **止盈止损** | 必须给出每只个股明确的**止损价位**和**止盈价位**建议 |
| **操作建议** | 明确给出：持有/加仓/减仓/卖出；加仓减仓清仓操作标准参考SW-buy和SW-sell规则 |

### 第三步：整体总结
- **要求：** 必须每只个股单独完整分析，展示资金面/技术面/消息面/估值分析全维度内容，不能只给结论，不能只输出速览摘要，必须输出完整分析内容
1. 对比本次更新前后持仓变化，列出用户当日操作：新开仓、平仓、加仓、减仓的具体个股和数量
2. 汇总整体持仓盈亏（含更新前后对比）
3. 整体仓位风险评估
4. 整体操作建议

## 三、输出保存
- 分析结果由 stockwin 总 skill 负责展示给用户，并保存到约定路径；本模块只输出分析内容

## 四、技术形态

### 箱体结构
	- 箱体结构（横盘整理）股价在一个区间内上下震荡，上有压力、下有支撑，突破上沿看涨，跌破下沿看跌。

### 三角形整理
	- 上升三角形：上边水平压力，下边逐步抬高，偏多。
	- 下降三角形：下边水平支撑，上边逐步降低，偏空。
	- 对称三角形：高点渐低、低点渐高，方向不明，突破后定方向。

### 旗形整理
	- 上升旗形：大涨后小幅回调震荡，继续向上概率大。
	- 下降旗形：大跌后小幅反弹震荡，继续向下概率大。

### 楔形整理
	- 上升楔形：看似上涨，实则越来越弱，多为诱多，末端易大跌。
	- 下降楔形：看似下跌，实则跌不动，末端易反弹。
	- 矩形整理基本等同于箱体，高低点大致水平，震荡后选择方向。

### 头肩顶
	- 左肩→头→右肩，跌破颈线，顶部反转下跌。

### 头肩底
	- 左肩→头→右肩，突破颈线，底部反转上涨。

### 双重顶（M 头） 
	- 两次冲高失败，跌破颈线看跌。

### 双重底（W 底）
	- 两次探底企稳，突破颈线看涨。

### 圆弧顶  
	- 上涨慢慢走缓，像锅盖，随后慢慢下跌。

### 圆弧底
	- 下跌慢慢走缓，像碗底，随后慢慢上涨。

### V 型反转（尖顶 / 尖底）
	- 快速暴跌后快速拉升，或暴涨后快速暴跌，力度极强，常伴随消息刺激。

### 顶部岛形反转 / 底部岛形反转
	- 两边有跳空缺口，中间像一座孤岛，是极强的反转信号。

### 通道
	- 上升通道低点不断抬高，高点不断创新高，沿两条上行平行线走。
	- 下降通道高点不断降低，低点不断创新低，沿两条下行平行线走。
