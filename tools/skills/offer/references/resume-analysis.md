# 简历分析

## 分析流程

1. 读取简历全文，提取：教育、工作经历、项目经历、技能、证书与奖项。
2. 明确目标岗位（用户告知或从 JD 提取），逐项比对匹配度。
3. 检查表达质量：
   - 是否量化（数字、百分比、时延、规模等）。
   - 是否采用"职责—动作—结果"结构。
   - 是否有与目标岗位无关的冗余内容。
4. 检查关键词覆盖：是否命中 JD 核心要求（语言、框架、中间件、行业术语）。
5. 识别风险点：空窗期、频繁跳槽、职责表述模糊、技能与岗位错位。

## 输出

- 匹配度结论（高/中/低 + 理由）。
- 按优先级排列的修改建议：高（影响匹配判断）、中（影响观感）、低（细节打磨）。
- 建议保留的亮点。
