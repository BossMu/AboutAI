# 岗位分析

对候选岗位按以下维度评估，结论尽量附带来源。

1. **城市**：通勤与生活成本、落户政策、该城市同行业机会密度。
2. **匹配性**：JD 硬性要求 vs 简历技能；行业/业务经验相关度；胜任度判断。
3. **薪资**：JD 或沟通口径 vs 该城市同岗位市场水平；JD 未写年薪时，主动检索该岗位在该城市的市场年薪区间（行业报告、招聘数据、公开面经等，浏览器按 SKILL.md「调用约定」选择），标注来源与日期。
4. **发展前景**：公司业务与行业趋势、岗位所在团队/产品的重要性、晋升路径。
5. **福利待遇**：五险一金基数与比例、补贴、奖金结构、期权/股票、年假与假期。
6. **工作时间**：加班强度、考勤/弹性工作、远程或混合办公。
